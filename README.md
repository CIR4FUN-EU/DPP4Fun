This repository includes two folders corresponding to two data models approaches :   

- **Ontology-resources**: includes DPP4Fun ontology and 11 data samples in three different 3 formats: OWL/XML, TTL, and JSON-LD      

- **AAS-resources**: includes AAS submodel templates for furniture sector and 11 data samples in JSON
